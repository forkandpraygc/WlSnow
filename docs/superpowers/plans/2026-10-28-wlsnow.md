# WlSnow Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A native Wayland application (Rust) that draws animated falling snowflakes on the desktop layer behind windows, for wlroots compositors (KWin best-effort), with a versioned Unix-socket control interface.

**Architecture:** Pure, unit-tested logic (config, snowflake simulation, frame rendering, control protocol) is separated from a thin Wayland glue layer (layer-shell surface + wl_shm buffer + frame loop) that is verified by running under a compositor. A detached thread serves a Unix socket, translating JSON control messages into mutations of a shared `Mutex<SharedState>` that the render loop reads each frame.

**Tech Stack:** Rust (edition 2021), `wayland-client`/`smithay-client-toolkit` 0.21 + `wayland-protocols-wlr` 0.3 (layer-shell), `memmap2` (shm), `clap` 4 (CLI), `serde`/`serde_json` (protocol), `rand` 0.10 (flake placement), `thiserror` (errors).

**Spec:** `docs/superpowers/specs/2026-10-28-wlsnow-design.md`

## Global Constraints

- Rust edition 2021; `cargo build`/`cargo test`/`cargo clippy` must pass clean.
- Layer: `zwlr_layer_shell_v1` surface on **background** layer (snow behind windows).
- **One output** only in MVP (no multi-monitor, no hotplug handling beyond a single output's configure/rescale).
- **Integer scale only** (`set_buffer_scale(scale)`, buffer sized ×scale). No fractional-scale protocol.
- KWin is **best-effort**; no KDE-specific code paths in MVP.
- No X11/XWayland, no GPU/EGL — CPU rendering into `wl_shm` (ARGB8888) only.
- Control protocol version `1`; every request/response carries `"v": 1`.

## Review Focus

Input classes the spec implies but no single task's happy-path test covers:

1. **Compositor without `zwlr_layer_shell_v1`** (e.g. GNOME): app must print a clear error and exit cleanly, not panic or spin. → Task 6, Step "handle missing layer-shell global".
2. **Zero flakes** (`--count 0`): simulation and renderer must not crash and must draw nothing. → Task 3 (empty-flakes test) and Task 4 (empty render test).
3. **Flake partially/fully off-screen or oversized**: renderer clips to bounds, never writes out of the buffer. → Task 4 (edge-clip test).
4. **Stride larger than `width × 4`**: renderer honors `stride`, not `width`. → Task 4 (stride test).
5. **Malformed / oversized / wrong-version control lines**: `handle_line` returns an error JSON line, never panics. → Task 5 (malformed + wrong-version tests).

- [ ] **Step 3: Implement `src/sim.rs`**

`new`: for `i in 0..count`, create a flake with `x = rng.random_range(0.0..width)`, `y = rng.random_range(0.0..height)`, `size = config.size` (diameter), `speed = config.speed` (exact, no jitter in MVP), `drift = rng.random_range(-config.drift..=config.drift)`.

`step(dt)` applies the pinned physics for every flake:

```rust
f.y += f.speed * dt;
f.x += f.drift * dt;
if f.x > self.width as f32 + f.size { f.x = -f.size; }
if f.x < -f.size { f.x = self.width as f32 + f.size; }
if f.y - f.size > self.height as f32 {
    f.y = -f.size;
    f.x = (f.x * 1.618_034 + f.speed) % self.width as f32;
}
```

Add `mod sim;` to the top of `src/main.rs`.

#[cfg(test)]
mod tests {
    use super::*;
    use crate::sim::Flake;

    fn pixel(buf: &[u8], stride: u32, x: u32, y: u32) -> [u8; 4] {
        let off = (y * stride + x * 4) as usize;
        [buf[off], buf[off+1], buf[off+2], buf[off+3]]
    }

    #[test]
    fn empty_clears_to_transparent() {
        let (w, h, stride) = (4u32, 4u32, 16u32);
        let mut buf = vec![255u8; (stride * h) as usize];
        render_frame(&mut buf, w, h, stride, &[]);
        assert!(buf.iter().all(|&b| b == 0));
    }

    #[test]
    fn single_flake_draws_white_center() {
        let (w, h, stride) = (20u32, 20u32, 80u32);
        let mut buf = vec![0u8; (stride * h) as usize];
        let f = Flake { x: 10.0, y: 10.0, size: 4.0, speed: 0.0, drift: 0.0 };
        render_frame(&mut buf, w, h, stride, &[f]);
        assert_eq!(pixel(&buf, stride, 10, 10), [255, 255, 255, 255]);
        assert_eq!(pixel(&buf, stride, 15, 10), [0, 0, 0, 0]); // distance 5 > radius 2
    }

    #[test]
    fn offscreen_flake_is_clipped() {
        let (w, h, stride) = (8u32, 8u32, 32u32);
        let mut buf = vec![0u8; (stride * h) as usize];
        let f = Flake { x: -100.0, y: 2.0, size: 50.0, speed: 0.0, drift: 0.0 };
        render_frame(&mut buf, w, h, stride, &[f]); // must not panic or write OOB
        assert!(buf.iter().all(|&b| b == 0)); // fully offscreen -> nothing drawn

    #[test]
    fn honors_stride_larger_than_width() {
        let (w, h, stride) = (2u32, 2u32, 16u32); // stride = 4px worth, width = 2px
        let mut buf = vec![0u8; (stride * h) as usize];

        render_frame(&mut buf, w, h, stride, &[f]);
        assert_eq!(pixel(&buf, stride, 0, 0), [255, 255, 255, 255]);
        assert_eq!(pixel(&buf, stride, 1, 1), [0, 0, 0, 0]); // outside drawn circle

### Task 6: Wayland glue + wiring

**Files:**
- Create: `src/wayland.rs`
- Modify: `src/main.rs`

**Interfaces:**
- Consumes: `Config`, `Simulation` (Task 3), `render_frame` (Task 4), `SharedState`/`spawn_server`/`socket_path` (Task 5).
- Produces: `pub fn run(state: std::sync::Arc<std::sync::Mutex<SharedState>>) -> Result<(), Box<dyn std::error::Error>>`.

- [ ] **Step 1: Write `src/main.rs` wiring**

```rust
mod config; mod sim; mod render; mod control; mod wayland;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let cli = <config::Cli as clap::Parser>::parse();
    let cfg = config::Config::from_cli(&cli);
    let state = std::sync::Arc::new(std::sync::Mutex::new(
        control::SharedState { config: cfg, paused: false, quit: false }
    ));
    let path = control::socket_path();
    control::spawn_server(path, state.clone());
    wayland::run(state)
}
```

- [ ] **Step 2: Implement `src/wayland.rs`**

Responsibilities (exact sctk 0.21 API is the implementer's to look up; behavior is fixed):
1. Connect via `Connection::connect_to_env`; build registry with `CompositorState`, `Shm`, and `OutputState`, and bind `zwlr_layer_shell_v1` (from `wayland-protocols-wlr`).
2. **If `zwlr_layer_shell_v1` is absent from the registry, print a clear error ("compositor does not support wlr-layer-shell") and exit nonzero — do not panic.** (Review Focus #1)
3. Pick the first `wl_output`; create a `wl_surface`, set it as a layer surface on the **background** layer, anchor top|bottom|left|right, size = output logical size.
4. Create a `SlotPool` (shm) and one `Slot`; on each frame, mmap the buffer (ARGB8888, `stride = width*4*scale`), call `render_frame` with the current flakes, `set_buffer_scale(scale)`, `attach` + `damage_buffer` + `commit`.
5. On `configure`, update stored `width`, `height`, and integer `scale`; reallocate the buffer if dimensions changed.
6. Frame loop: on each frame callback, lock `state`, read `config`; if `quit` is true, exit; else if not `paused`, `simulation.step(dt)` and `render_frame` + commit; re-request the next frame callback. Keep a `Simulation` sized to the output; if `config.flake_count` differs from `simulation.flakes.len()`, rebuild via `Simulation::new`.
7. Use a real elapsed-time source (e.g. `std::time::Instant`) for `dt`.
